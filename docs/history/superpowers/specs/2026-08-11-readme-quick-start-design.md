# README 与 AGENTS 精简设计

## 目标

将仓库首页从完整运维手册压缩为快速上手文档，使新读者能在几分钟内理解项目、完成安装并启动 Web 工作台；同时压缩 Agent 交接文档中的重复状态说明，保留全部硬性约束。

## README 结构

1. 项目定位与当前阶段。
2. 核心能力：多助手、项目式写作、选区改写、Agent 聊天、记忆与 Scheduler。
3. 环境要求与首次安装。
4. Web 工作台启动命令。
5. 常用 CLI 与测试命令。
6. 关键目录与文档链接。
7. 当前验证基线。

目标长度为 90 至 110 行，命令保持可直接执行。

## 内容调整

- 删除 README 中的完整运行日志示例、阶段路线图和冗长机制表。
- 保留指定 conda Python、`.env`、Node.js、API Key、Web 生产启动与开发启动说明。
- 保留最常用的助手管理、单次任务、Scheduler 和测试命令。
- 将 Windows Task Scheduler 的完整 XML 与导入、验证、导出步骤移动到 `docs/windows-task-scheduler.md`，README 只提供简短说明和链接。
- 架构细节继续以 `docs/phase1-architecture.md` v1.11 为单一事实来源。

## AGENTS 结构

1. 项目定位、当前阶段和验证基线。
2. 新会话必读顺序与阶段门。
3. 指定 Python 环境和常用验证命令。
4. 精简代码地图。
5. 不可删减的架构、隔离、SQL、密钥、TDD、工作区和 Git 规则。
6. 已知暂缓项。

删除重复的阶段 3/4 验收明细和与代码地图重复的能力长列表；修正 Git 已有首次提交并配置 `origin/main` 的状态。目标长度为 70 至 85 行。

## 验收标准

- README 不包含伪命令或失效路径。
- Windows Task Scheduler 详细操作没有丢失，只从主阅读路径下沉。
- Python `123/123`、记忆隔离 `9/9`、前端 `30/30` 基线保持可见。
- README 总长度处于目标范围附近，并能独立指导首次安装和 Web 启动。
- AGENTS 的硬性约束、测试命令和阶段门完整保留，且不再包含过期 Git 状态。
