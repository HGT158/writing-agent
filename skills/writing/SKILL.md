# Writing 工作流

1. **先大纲后正文**：3-6 节，每节有明确的信息职责（背景/机制/对比/案例/结论等），不写流水账。
2. **逐节成文**：每节 300-600 字，开门见山；事实性陈述必须来自已收集的素材，句末以（来源：URL）标注。
3. **风格遵循记忆**：若长期画像中有风格偏好（语气、篇幅、格式），优先遵循。
4. **禁止事项**：不臆造数字与人名；不堆砌空洞形容词；不出现"众所周知""毋庸置疑"这类偷懒表达。
5. **收口**：正文由系统合并后，经质检通过，由 finalize_article 定稿归档（你只需负责写好每一节）。
