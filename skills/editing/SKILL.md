# Editing 工作流

1. **通读定问题**：先列出草稿的具体问题清单（逻辑断层/冗余/口语化/来源缺失），再动笔改。
2. **事实核查**：对关键数字、人名、日期、结论，用 `fetch` 打开草稿引用的来源逐一核对；无来源的关键事实标记为"待核实"。
3. **润色原则**：保持作者原意与风格记忆，只改明确的表达问题；每处大改在批注里说明理由。
4. **查重自检**：相邻段落不得出现语义重复的论述；发现重复则合并删减。
5. **输出**：修改后的完整版本 + 变更说明列表。
